# Belot Scorer: Web Demo Roadmap

Each phase gets its own detailed plan in this folder, written when the previous phase is done. Each phase ends with software that runs and is tested.

**Specs:** `docs/design-handoff/{README,GAME_RULES,DATA_MODEL}.md`, screens in `docs/design-handoff/screens/png/`
**Glossary:** `CONTEXT.md` · **Decisions:** `docs/adr/0001–0005`

## Global constraints (apply to every phase)

- Single Vite + React 19 SPA, TypeScript `strict`, pnpm, React Compiler on (ADR 0001).
- `src/core/**` imports nothing from React, DOM or browser globals. Enforced by `tsconfig.core.json` (no `dom` lib), Biome `noRestrictedImports` (bans importing `react`/`react-dom`/`react-router`/`zustand`/`idb-keyval`), and Biome `noRestrictedGlobals` (bans the `Date` global). `Math.random` isn't lint-enforced — Biome has no rule that restricts one member of a global object — so it's a code-review convention, not a checked one.
- `core` is pure: no `Date.now()`, no random ids inside. Callers pass `id`/`date` in.
- Zustand store = thin shell over `core` functions. Totals, dealer, allowed declarations and verdict are **derived**, never stored (ADR 0002).
- No barrel `index.ts` files. Import from the defining module.
- Lazy `import()` for share/import (QR, camera, compression), photo cropping, and non-table routes. Preload on hover/focus.
- Narrow Zustand selectors. No `useEffect` for game logic (auto-end happens inside the save action).
- UI copy is final Bulgarian text from the handoff, kept in `src/core/strings.ts` (functions where words must agree with the subject).
- Styling: Tailwind v4 utilities driven by CSS variables written from `src/core/tokens.ts` (ADR 0004). Nunito via `@fontsource-variable/nunito`.
- Persistence: one versioned JSON document in IndexedDB (`idb-keyval`) + photo Blobs keyed by `photoId` (ADR 0003).
- Ids: `nanoid(10)`. Share payload `v: 2` only (ADR 0005).
- Tests: Vitest (core, test-first), React Testing Library (key flows). Lint and format: Biome.
- Conventional Commits.

## Phases

| # | Phase | Delivers | Plan |
|---|---|---|---|
| 1 | Scaffold & tooling | Vite app boots. Lint, typecheck (app + core), test and build all pass. Core import boundary enforced. | `2026-09-25-phase-1-2-scaffold-and-core.md` |
| 2 | Core domain | Types + Zod schemas, rules config, allowed declarations, `resolve`, `scoreDeal`, match transitions, series, roster/seat ops, leaderboard. Golden cases + parity check against the prototype. | same file |
| 3 | Store & persistence | Zustand store (roster, stats, match, settings) + `persist` over idb-keyval, versioned Zod migrations, photo Blob store, init-once hydration. | `2026-09-25-phase-3-store-and-persistence.md` |
| 4 | UI foundation | `tokens.ts` → CSS vars → Tailwind `@theme`, theme/felt switching, Nunito, `ui/` primitives (Sheet on vaul, Popover/Dialog, Button, Avatar, Segmented, Chip), router shell with lazy routes + ErrorBoundary per route. | later |
| 5 | Screens | home → player register/edit (emoji; photo crop lazy) → setup + seat sheet → table (seats, popover, dealer, coaster) → contract sheet → deal end (resolution step + points step) → clear/undo → history → match end + series → leaderboard → settings (themes, felts, rules). RTL tests for the full deal and match flow. | later |
| 6 | Share & import | Payload v2 + Zod, codec (injected compressor so `core` stays platform-free), link `#belot=`, multi-part QR (`qrcode-generator`), scanner (`qr-scanner`), `.belot` file with optional photos, merge/continue/replace. All lazy-loaded. | later |
| 7 | PWA & polish | `vite-plugin-pwa` (autoUpdate, offline), manifest/icons, 150–200 ms sheet transitions, a11y pass, Playwright happy path, bundle check. | later |

Deploy (Vercel / Cloudflare Pages) is deferred. Share links use `location.origin` at runtime.
